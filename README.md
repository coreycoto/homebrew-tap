# Coreycoto Homebrew Tap

Private Homebrew tap for Corey Coto developer tools.

## git-slop

```bash
brew tap coreycoto/tap git@github.com:coreycoto/homebrew-tap.git
brew install coreycoto/tap/git-slop
git-slop version
```

The `git-slop` formula is generated from the `coreycoto/git-slop` release
manifest with `scripts/update_homebrew_formula.py` in that repository. Keep this
repository private until the tap is intentionally made public.
